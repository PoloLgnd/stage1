## Как запустить проект?

### Установка виртуального окружения

==Windows==

```powershell
python -m venv venv
venv/Scripts/activate
```

==Linux==

```Bash
python3 -m venv venv
venv/bin/activate
```

### Установка зависимостей

``` powershell
pip install -r requirements.txt
```
