## Как запустить проект?

### 1. Установка виртуального окружения

==Windows==

```powershell
python -m venv venv
venv\Scripts\activate
```

==Linux==

```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Установка зависимостей

```powershell
pip install -r requirements.txt
```

### 3. Запуск сервера

```powershell
python app.py
```

После запуска приложение доступно по адресу: **http://127.0.0.1:5000**

База данных SQLite (`instance/conferences.db`) со справочником помещений и учетной записью администратора инициализируется автоматически при первом запуске.

## Страницы приложения

1. **Главная (`/`)** — шапка, меню, адаптивный слайдер с автопрокруткой (3 секунды), кнопка «Забронировать помещение», карточки помещений с типами.
2. **Регистрация (`/register`)** — валидация 5 полей в JS и Python, подсветка ошибок, подсказки по формату.
3. **Авторизация (`/login`)** — форма входа, переход в личный кабинет или админ-панель, ссылка «Еще не зарегистрированы? Регистрация».
4. **Новая заявка (`/booking/new` или `/rooms`)** — выбор помещения, даты и способа оплаты («При очном посещении» или «Перевод по СБП»).
5. **Личный кабинет (`/cabinet`)** — список своих заявок, цветные статусы, удаление новой заявки, форма отзыва для статуса «Завершено».
6. **Панель администратора (`/admin`)** — фильтр заявок, карточки клиентов, смена статуса с сохранением в БД, удаление заявок.
